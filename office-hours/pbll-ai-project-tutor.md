# Office Hours 2026-07-22 — AI PBLL Project Tutor for Persian-speaking English learners

**Decision: A → B staged.** Stage A = concierge pilot (no code): one paid 4-week PBLL cohort, 10–15 existing students, private Telegram group, Hiwa facilitates with AI behind the scenes; every exchange logged as spec + data seed. Stage B = Telegram bot MVP (AI facilitator running driving question → Product Square → NTK wall → critique/revision → public product), built only if Stage A passes.

**Two-gate validation:** Gate 1 — personal DMs to 17 named past buyers (Vahid, Hoshang, Alireza, …); ≥3 paid deposits within a week or kill. Gate 2 — offer to the 20k email list; ≥10 paid within 2 weeks or kill. Kill rule sends the shared ~$750 budget + attention to the IranFluent checkout repair.

**Premises (locked, D12):** (1) first users = existing students; (2) enemy = free ChatGPT, win on rial-payable access + Persian guidance + trust + structure, future NFLRC partnership option; (3) demand proven for old product (~5B Toman, 20k list, 100+ nameable buyers) — AI-era offer unproven, pilot validates; (4) Telegram-first; (5) runs alongside checkout repair with explicit kill rule; (6) PBLL facilitation is the wedge, moat = audience trust + accumulated learner data + outcomes (revised after Codex cold read).

**Codex second opinion:** structure alone is copyable pedagogy; 90-day failure mode = completion collapse (loyalty purchases ≠ validation; real test = completion + publication + repurchase); missing pieces (now constraints): sharp promised outcome, thresholds, founder-time budget (10h/wk cap), retention hypothesis, publication-consent policy (pre-launch blocker), sanctions/API risk.

**Assignment:** within 72h send the one-paragraph Persian pilot offer (named outcome, real Toman price, start date, consent line) as personal DMs to the 17 named buyers; report replies/yes/paid.
